A podracing game in the style of *Star Wars: Episode I – The Phantom Menace* (1999): fly Anakin's pod across the Tatooine dune sea, through canyons and under sandstone arches. Built with Vite, TypeScript and three.js, for the browser and the desktop (Electron).

**Everything is procedural.** Terrain, track, podracer, sky and textures are generated by code at runtime; the repository contains no images, audio or 3D models. The only bundled third-party asset is the Orbitron font (SIL Open Font License) via `@fontsource`.

## Status

Graphics prototype: the pod flies the course on autopilot. Keys: **C** cycles cameras (chase, cockpit, trackside, showcase orbit), **1 / 2 / 3** set quality. Gameplay, HUD, menus and audio are next.

## Run

```bash
npm install
npm run dev      # http://localhost:5175/
npm run build    # tsc --noEmit + vite build → dist/
npm run app      # build and run as a desktop app (Electron)
```

See [AGENTS.md](AGENTS.md) for architecture, conventions and how to verify changes.
