A podracing game in the style of *Star Wars: Episode I – The Phantom Menace* (1999): fly Anakin's pod across the Tatooine dune sea, through canyons and under sandstone arches. Built with Vite, TypeScript and three.js, for the browser and the desktop (Electron).

**Everything is procedural.** Terrain, track, podracer, sky and textures are generated by code at runtime; the repository contains no images, audio or 3D models. The only bundled third-party assets are the Orbitron and News Cycle fonts (SIL Open Font License) via `@fontsource`.

## Status

Playable MVP: the Boonta Eve Classic, three laps against five rivals (Sebulba, Gasgano, Mawhonic, Ody Mandrell, Aldar Beedo) on three circuit classes: **Amateur**, **Semi-Pro**, **Galactic** (rival pace, cornering, boost use, ramming and damage taken scale with it). Cinematic intro with rival introductions, countdown with a perfect-start window, slow-motion crashes and finish, results with best record per class. Procedural engine sound with doppler flybys and music; English and Italian.

| Keyboard | Gamepad | Action |
|---|---|---|
| W / Up | RT | Throttle |
| S / Down | LT | Air brakes (slow down, tighter turn) |
| A D / Left Right | Left stick | Steer |
| Shift / Space | A | Boost (builds engine heat; near misses cool it) |
| Double-tap A or D | X / B | Barrel roll: sidestep, shoulders rivals aside |
| Q / E | LB / RB | Knife edge: tilt 90 degrees to slip past rocks |
| C | Y | Camera (chase, far, cockpit) |
| R | View | Back to the track |
| Esc / P | Start | Pause |

## Run

```bash
npm install
npm run dev      # http://localhost:5175/
npm run build    # tsc --noEmit + vite build → dist/
npm run app      # build and run as a desktop app (Electron)
```

See [AGENTS.md](AGENTS.md) for architecture, conventions and how to verify changes.
